# Flow.Launcher.Plugin.Zai

A [Flow Launcher](https://github.com/Flow-Launcher/Flow.Launcher) plugin that opens [Zai AI](https://z.ai) in your browser with your prompt.

## Features

- Type your prompt and press Enter to launch Zai in your browser
- Incognito mode available as a second result

## Usage

Use the action keyword `zai` followed by your prompt:

```
zai how do I reverse a list in Python
```
